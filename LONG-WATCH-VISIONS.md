# THE LONG WATCH: VISIONS — report

Every one of the 47 entries opens on a hero visual. **22 are real images** of the actual thing (rock art, artefact, broadsheet, newspaper page, government document, Navy video still) and **25 are original artist's renderings** made for this site. Each rendering carries the permanent label "ARTIST'S RENDERING — based on the recorded account", both burned into the image and as a tag beside it. The Tulli hoax rendering says it depicts a hoax text. 75 visuals in total (several entries have a real document plus a rendering); every one has 1–3 hotspots. No portrait photographs of real people.

Renderings are drawn from code in `tools/lw-art/` (SVG scenes in each era's style → PNG via headless Chrome → AVIF/WebP). Real images were licence-checked on their Wikimedia Commons file pages (metadata in the `lw-research-results` branch).
